## ⚡ 快速摘要

### 教學流程總覽

```
玩家首次登入
    ↓
播放過場動畫
    ↓
步驟1：財神引導 → 點擊遊戲 ICON
    ↓
步驟2：財神引導 → 點擊 SPIN
    ↓
步驟3：固定腳本觸發 FG → 播放報獎動畫
    ↓
步驟4：財神引導 → 點擊返回大廳
    ↓
教學結束，帳號標記完成 → 進入大廳後續流程
```

### 核心設計原則

- 教學為**強制完成**，不提供跳過機制
- 財神 NPC 全程陪伴引導
- 指定遊戲可由**後台彈性設定**
- FG 由固定腳本觸發，確保新手體驗到完整報獎流程
