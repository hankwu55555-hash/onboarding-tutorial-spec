# 04 · 後台設定規格

[← 回目錄](../README.md)

---

教學流程中的關鍵參數可由後台彈性配置，無需改動程式碼即可調整教學內容。

---

## 可配置項目

| 設定項目 | 說明 |
|---------|------|
| 指定遊戲 | 可選擇要引導玩家進入的老虎機遊戲（例如 Money Mage、Phoenix Legend 等） |
| 財神台詞 | 各步驟的財神引導文字可後台編輯，支援多語言 |
| FG 腳本 | FG 觸發腳本綁定指定遊戲，更換遊戲時需同步更新腳本 |
| 預設下注金額 | 步驟2 SPIN 時使用的固定下注金額 |
| 備援遊戲 | 指定遊戲不可用時的 fallback 遊戲 |

---

## 設定注意事項

- 更換指定遊戲時，FG 腳本需**同步更新**，否則腳本無法在新遊戲中正確觸發
- 備援遊戲（Fallback）必須設定，避免指定遊戲下架時教學無法進行
- 台詞編輯需提供所有支援語言的版本，缺少語言版本時應 fallback 至預設語言（繁體中文）
