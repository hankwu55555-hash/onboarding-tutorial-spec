# 04 · 後台設定規格

[← 回目錄](../README.md)

教學流程中的關鍵參數可由後台介面彈性配置，無需改動程式碼即可調整教學內容。

---

## 設定區塊總覽

後台設定頁面分為以下 4 個區塊：

| 區塊 | 說明 |
|------|------|
| A · 遊戲設定 | 指定引導遊戲與備援遊戲 |
| B · SPIN 腳本設定 | 各次 SPIN 的結果腳本與 FG 設定 |
| C · 財神台詞設定 | 各步驟的引導台詞（多語言） |
| D · 數值設定 | 教學期間的下注金額 |

---

## 區塊 A｜遊戲設定

### A-1 指定引導遊戲

| 欄位 | 規格 |
|------|------|
| 欄位名稱 | 指定引導遊戲 |
| 欄位類型 | 下拉選單（單選） |
| 選項來源 | 系統現有上架遊戲清單（動態載入） |
| 必填 | ✅ 必填 |
| 預設值 | 無（需手動設定） |
| 驗證規則 | 所選遊戲必須為「上架中」狀態，否則儲存時顯示錯誤 |
| 備註 | 更換遊戲時系統自動提示需同步更新 SPIN 腳本（見區塊 B） |

### A-2 備援遊戲（Fallback）

| 欄位 | 規格 |
|------|------|
| 欄位名稱 | 備援遊戲 |
| 欄位類型 | 下拉選單（單選） |
| 選項來源 | 系統現有上架遊戲清單（動態載入） |
| 必填 | ✅ 必填 |
| 預設值 | 無（需手動設定） |
| 驗證規則 | 不可與指定引導遊戲相同；所選遊戲必須為「上架中」狀態 |
| 觸發時機 | 指定引導遊戲下架或不可用時自動套用 |

---

## 區塊 B｜SPIN 腳本設定

教學期間共 5 次 SPIN，每次結果皆由腳本控制，可於後台個別設定。

### B-1 第 1〜4 次 SPIN 腳本

| 欄位 | 規格 |
|------|------|
| 欄位名稱 | SPIN 1 結果 ／ SPIN 2 結果 ／ SPIN 3 結果 ／ SPIN 4 結果 |
| 欄位類型 | 下拉選單（單選） |
| 選項內容 | 依指定遊戲的可用腳本結果清單（例如：小贏、普通、無贏、特定符號組合等） |
| 必填 | ✅ 必填 |
| 預設值 | 無（需手動設定） |
| 備註 | 選項清單隨指定引導遊戲變動，更換遊戲後需重新設定 |

### B-2 第 5 次 SPIN（FG 觸發）

| 欄位 | 規格 |
|------|------|
| 欄位名稱 | FG 觸發腳本 |
| 欄位類型 | 下拉選單（單選） |
| 選項內容 | 依指定遊戲的可用 FG 腳本清單 |
| 必填 | ✅ 必填 |
| 預設值 | 無（需手動設定） |
| 備註 | 第 5 次固定觸發 FG，此欄位用於選擇 FG 期間的演出腳本（局數、符號等） |

### B-3 腳本狀態提示

| 情境 | 系統行為 |
|------|---------|
| 指定遊戲變更 | 系統顯示警示：「更換遊戲後，SPIN 腳本需重新設定，原設定已清空」 |
| 腳本未設定即儲存 | 儲存失敗，提示「請完成所有 SPIN 腳本設定」 |

---

## 區塊 C｜財神台詞設定

每個步驟的財神台詞可獨立編輯，並支援多語言版本。

### 台詞欄位規格（每個步驟共用以下結構）

| 欄位 | 規格 |
|------|------|
| 欄位類型 | 多行文字輸入框 |
| 字數上限 | 50 字（超過時儲存警告，避免 UI 顯示溢出） |
| 必填 | ✅ 繁體中文為必填；其他語言為選填（缺少時 fallback 至繁體中文） |
| 支援語言 | 繁體中文、簡體中文、英文（可依需求擴充） |

### 各步驟台詞欄位

| 步驟 | 欄位名稱 | 預設文字（簡體中文） |
|------|---------|------------------|
| 步驟 1 | 進入遊戲引導台詞 | 「欢迎来到金猴爷！点击游戏，和我一起体验豪富之旅！」 |
| 步驟 2 | SPIN 引導台詞 | 「点击 SPIN 按钮旋转老虎机」 |
| 步驟 4 | 返回大廳引導台詞 | 「点击返回大厅，让我们继续在金猴爷体验更多好玩游戏吧！」 |

> ⚠️ **注意**：台詞中若含有遊戲名稱（如「金猴爷」），更換品牌時需手動同步更新。

---

## 區塊 D｜數值設定

### D-1 教學預設下注金額

| 欄位 | 規格 |
|------|------|
| 欄位名稱 | 教學期間預設下注金額 |
| 欄位類型 | 數字輸入框 |
| 單位 | 遊戲幣 |
| 必填 | ✅ 必填 |
| 最小值 | 1（不可為 0 或負數） |
| 預設值 | TBD（待數值企劃確認） |
| 備註 | 教學期間玩家無法自行調整下注金額，固定使用此數值 |

---

## 儲存與發佈規則

| 規則 | 說明 |
|------|------|
| 草稿儲存 | 所有欄位可儲存為草稿，未發佈不影響線上教學流程 |
| 發佈 | 發佈前系統自動驗證所有必填欄位是否完整 |
| 發佈後生效時機 | 發佈後立即生效，下一位觸發教學的新玩家即使用新設定 |
| 版本記錄 | 每次發佈自動記錄操作者與時間戳，可查閱歷史版本 |
