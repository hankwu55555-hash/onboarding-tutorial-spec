# 03 · 介面顯示 & 演出動態

[← 回目錄](../README.md)

本章節列出新手教學全流程中，所有介面上會發生的演出與動態事件。

---

## 完整演出流程總覽

```
[1] 過場動畫
      ↓
[2] 財神登場
      ↓
[3] 步驟1 引導：點擊遊戲 ICON
      ↓
[4] 進入遊戲過場
      ↓
[5] 步驟2 引導：第1次 SPIN 手指提示
      ↓
[6] SPIN 1〜4 演出（腳本結果）
      ↓
[7] 第5次 SPIN → FG 觸發演出
      ↓
[8] FG 結束報獎動畫
      ↓
[9] 步驟4 引導：返回大廳
      ↓
[10] 教學結束收尾動畫
```

---

## 各節點演出規格

### [1] 過場動畫

| 項目 | 規格 |
|------|------|
| 時機 | 玩家首次登入後立即播放 |
| 內容 | 品牌過場動畫（TBD，由美術提供） |
| 可跳過 | ❌ 不可跳過 |
| 結束後 | 自動銜接 [2] 財神登場 |

---

### [2] 財神登場

| 項目 | 規格 |
|------|------|
| 時機 | 過場動畫結束後 |
| 動畫 | 財神從畫面外飛入，停駐於畫面下方 |
| 對話氣泡 | 文字逐字顯示（打字效果），顯示步驟1引導台詞 |
| 台詞 | 「欢迎来到金猴爷！点击游戏，和我一起体验豪富之旅！」 |
| 背景遮罩 | 非引導區域加上半透明遮罩，僅指定遊戲 ICON 可點擊 |
| 手指提示 | 動態手指圖示指向指定遊戲 ICON，持續閃爍直到玩家點擊 |

---

### [3] 步驟1 引導：點擊遊戲 ICON

| 項目 | 規格 |
|------|------|
| 玩家操作 | 點擊指定遊戲 ICON |
| 點擊後動畫 | 手指提示消失；財神播放揮手送別動畫 |
| 過場 | 進入遊戲的載入過場動畫 |

---

### [4] 進入遊戲過場

| 項目 | 規格 |
|------|------|
| 內容 | 遊戲載入動畫（與正常進入遊戲流程一致） |
| 財神顯示 | 財神持續顯示於畫面角落，不消失 |
| 結束後 | 自動銜接 [5] SPIN 手指提示 |

---

### [5] 步驟2 引導：第1次 SPIN 手指提示

| 項目 | 規格 |
|------|------|
| 時機 | 進入遊戲畫面後自動觸發 |
| 對話氣泡 | 財神顯示台詞：「点击 SPIN 按钮旋转老虎机」 |
| 手指提示 | 動態手指圖示指向 SPIN 按鈕，持續閃爍 |
| 顯示次數 | **僅第 1 次 SPIN 顯示**，玩家點擊後手指提示與台詞同時消失，後續 SPIN 不再出現 |
| 背景遮罩 | 非 SPIN 按鈕區域加上半透明遮罩 |

---

### [6] SPIN 1〜4 演出

| 項目 | 規格 |
|------|------|
| 演出內容 | 依腳本結果播放對應轉輪演出（與正式遊戲演出一致） |
| 財神動態 | 每次 SPIN 結束後，財神播放對應反應動畫（小贏：鼓掌；無贏：搖頭鼓勵） |
| 對話氣泡 | 每次 SPIN 結束後財神無額外台詞（保持安靜，避免干擾） |
| 手指提示 | 第 1 次點擊後不再顯示，玩家自行點擊後續 SPIN |
| 遮罩狀態 | 移除遮罩，但僅 SPIN 按鈕可操作，其他功能按鈕仍不可用 |

---

### [7] 第5次 SPIN → FG 觸發演出

| 項目 | 規格 |
|------|------|
| 時機 | 第 5 次 SPIN 結束後 |
| 觸發動畫 | FG 觸發演出（與正式遊戲 FG 觸發動畫一致，腳本控制） |
| 財神動態 | FG 觸發瞬間財神播放誇張慶祝動畫（跳躍、撒金幣等） |
| 對話氣泡 | TBD（可由企劃設計 FG 觸發時的財神台詞，例如：「大獎來了！」） |
| 後續 | 自動進入 FG 演出流程 |

---

### [8] FG 結束報獎動畫

| 項目 | 規格 |
|------|------|
| 內容 | FG 報獎演出（與正式遊戲一致，腳本控制結果） |
| 財神動態 | 報獎期間財神持續慶祝動畫 |
| 報獎結束後 | 自動銜接 [9] 返回大廳引導 |

---

### [9] 步驟4 引導：返回大廳

| 項目 | 規格 |
|------|------|
| 時機 | FG 報獎動畫播放完畢後 |
| 對話氣泡 | 財神顯示台詞：「点击返回大厅，让我们继续在金猴爷体验更多好玩游戏吧！」 |
| 手指提示 | 動態手指圖示指向「返回大廳」按鈕，持續閃爍直到玩家點擊 |
| 背景遮罩 | 非返回大廳按鈕區域加上半透明遮罩 |

---

### [10] 教學結束收尾動畫

| 項目 | 規格 |
|------|------|
| 時機 | 玩家點擊「返回大廳」後 |
| 動畫 | 財神揮手送別，淡出消失 |
| 帳號標記 | 同步寫入「教學已完成」狀態至伺服器 |
| 後續 | 進入大廳後續流程（不在本規格範疇） |

---

## 財神動畫狀態一覽

| 觸發情境 | 財神動畫 |
|---------|---------|
| 登場 | 飛入停駐動畫 |
| 說話中 | 嘴部動畫 + 對話氣泡打字效果 |
| SPIN 小贏 | 鼓掌慶祝 |
| SPIN 無贏 | 搖頭 + 鼓勵手勢 |
| FG 觸發 | 誇張跳躍 + 撒金幣特效 |
| 報獎期間 | 持續慶祝擺動 |
| 教學結束 | 揮手送別 + 淡出 |

> ⚠️ **待確認**：各動畫狀態的素材清單、規格與時長，需由美術部門另行提供。
