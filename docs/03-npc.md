# 03 · 財神 NPC 規格

[← 回目錄](../README.md)

---

## 角色定位

- 全程陪伴玩家完成教學的引導角色
- 以對話氣泡方式顯示引導文字
- 每個步驟完成後有對應的慶祝動畫（點頭、揮手等）

---

## 顯示規格

| 項目 | 規格 |
|------|------|
| 顯示位置 | 固定於畫面下方或側邊，不遮擋主要操作區 |
| 對話氣泡 | 文字逐字顯示動畫（打字效果），完成後顯示手指點擊提示 |
| 語言 | 依玩家裝置語系顯示對應語言版本 |

---

## 各步驟動畫狀態

| 步驟 | 財神動畫 |
|------|---------|
| 步驟1：引導點擊 ICON | 揮手歡迎動畫 |
| 步驟2：引導點擊 SPIN | 指向 SPIN 按鈕的手勢動畫 |
| 步驟3：FG 觸發中 | 興奮慶祝動畫 |
| 步驟4：引導返回大廳 | 揮手送別動畫 |

> ⚠️ **待確認**：各步驟動畫清單與素材規格需由美術部門另行提供。
