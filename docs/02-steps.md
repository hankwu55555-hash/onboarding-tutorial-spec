# 02 · 教學步驟規格

[← 回目錄](../README.md)

---

## 步驟 1｜點擊 ICON 進入遊戲

| 項目 | 內容 |
|------|------|
| 觸發時機 | 過場動畫結束後立即觸發 |
| 財神台詞 | 「欢迎来到金猴爷！点击游戏，和我一起体验豪富之旅！」 |
| 玩家操作 | 點擊指定遊戲 ICON 進入老虎機 |
| 指定遊戲 | 由後台彈性設定（詳見[後台設定規格](04-config.md)） |
| UI 提示 | 手指點擊動畫指向指定 ICON，其餘 ICON 不可點擊 |

---

## 步驟 2｜引導點擊 SPIN（共 5 次）

| 項目 | 內容 |
|------|------|
| 觸發時機 | 玩家進入遊戲後自動顯示引導 |
| 財神台詞 | 「点击 SPIN 按钮旋转老虎机」 |
| 玩家操作 | 點擊 SPIN 按鈕（需點擊共 5 次） |
| UI 提示 | 手指點擊動畫指向 SPIN 按鈕（**僅第 1 次 SPIN 顯示**，點擊後消失，後續 SPIN 不再出現）；其餘按鈕不可操作 |
| 下注金額 | 使用固定預設下注金額，玩家無法調整 |

### SPIN 腳本規格

教學期間所有 SPIN 結果與演出均由**固定腳本控制**，非隨機產生：

| SPIN 次數 | 結果 | 說明 |
|----------|------|------|
| 第 1 次 | 腳本指定結果 | 由企劃設計，確保有基本演出 |
| 第 2 次 | 腳本指定結果 | 由企劃設計 |
| 第 3 次 | 腳本指定結果 | 由企劃設計 |
| 第 4 次 | 腳本指定結果 | 由企劃設計 |
| **第 5 次** | **必定觸發 FG** | 固定腳本保證觸發 Free Game |

> ⚠️ **注意**：教學期間的所有 SPIN 結果均與正常遊戲機率完全隔離，使用獨立腳本引擎執行，不影響正式 RNG。

> ⚠️ **待確認**：第 1〜4 次 SPIN 的腳本結果設計（建議由企劃提供，兼顧演出豐富度與節奏）。

---

## 步驟 3｜FG 演出（第 5 次 SPIN 觸發）

| 項目 | 內容 |
|------|------|
| 觸發條件 | 第 5 次 SPIN 時由腳本強制觸發 FG |
| 演出內容 | FG 演出流程與正式遊戲一致（腳本控制結果） |
| 玩家感知 | 玩家不感知為腳本觸發，體驗與正常 FG 一致 |
| 防濫用 | 腳本引擎僅於新手教學期間有效，帳號首次完成教學後即停用 |

> ⚠️ **待確認**：FG 期間的腳本結果設計（由企劃提供，需有足夠的報獎感）。

---

## 步驟 4｜報獎完成，返回大廳

| 項目 | 內容 |
|------|------|
| 觸發時機 | FG 報獎動畫播放完畢後 |
| 財神台詞 | 「点击返回大厅，让我们继续在金猴爷体验更多好玩游戏吧！」 |
| 玩家操作 | 點擊「返回大廳」按鈕 |
| 教學狀態 | 點擊後新手教學正式結束，帳號標記為「已完成教學」 |
| 後續流程 | 返回大廳後由大廳後續流程接手（不在本規格範疇） |
