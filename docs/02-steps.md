# 02 · 教學步驟規格

[← 回目錄](../README.md)

---

## 步驟 1｜點擊 ICON 進入遊戲

| 項目 | 內容 |
|------|------|
| 觸發時機 | 過場動畫結束後立即觸發 |
| 財神台詞 | 「歡迎來到金猴爺！點擊遊戲，和我一起體驗豪富之旅！」 |
| 玩家操作 | 點擊指定遊戲 ICON 進入老虎機 |
| 指定遊戲 | 由後台彈性設定（詳見[後台設定規格](04-config.md)） |
| UI 提示 | 手指點擊動畫指向指定 ICON，其餘 ICON 不可點擊 |

---

## 步驟 2｜引導點擊 SPIN

| 項目 | 內容 |
|------|------|
| 觸發時機 | 玩家進入遊戲後自動顯示引導 |
| 財神台詞 | 「點擊 SPIN 按鈕旋轉老虎機」 |
| 玩家操作 | 點擊 SPIN 按鈕 |
| UI 提示 | 手指點擊動畫指向 SPIN 按鈕，其餘按鈕不可操作 |
| 下注金額 | 使用固定預設下注金額，玩家無法調整 |

---

## 步驟 3｜固定腳本觸發 Free Game

| 項目 | 內容 |
|------|------|
| 觸發方式 | 教學專用固定腳本強制觸發 FG（不依賴正常機率） |
| 目的 | 確保新玩家在教學中體驗到 FG 的完整流程與獎勵感受 |
| 玩家感知 | 玩家不感知為強制觸發，體驗與正常 FG 一致 |
| 防濫用 | FG 腳本僅於新手教學期間有效，帳號首次觸發後即失效 |

---

## 步驟 4｜報獎完成，返回大廳

| 項目 | 內容 |
|------|------|
| 觸發時機 | FG 報獎動畫播放完畢後 |
| 財神台詞 | 「點擊返回大廳，讓我們繼續在金算令體驗更多好玩遊戲吧！」 |
| 玩家操作 | 點擊「返回大廳」按鈕 |
| 教學狀態 | 點擊後新手教學正式結束，帳號標記為「已完成教學」 |
| 後續流程 | 返回大廳後由大廳後續流程接手（不在本規格範疇） |
