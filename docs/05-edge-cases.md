# 05 · 邊界情境（Edge Cases）

[← 回目錄](../README.md)

---

| # | 情境 | 預期行為 |
|---|------|---------|
| 1 | 玩家在教學中途關閉 App 或斷線 | 重新開啟後從中斷的步驟繼續，不重頭開始（需伺服器記錄教學進度） |
| 2 | 後台指定遊戲未設定或遊戲下架 | 系統自動 fallback 至備援遊戲，避免教學無法進行 |
| 3 | 玩家嘗試點擊非引導區域的按鈕 | 教學期間非引導區域的所有按鈕均為不可點擊狀態（灰化或遮罩處理） |
| 4 | 玩家帳號已完成教學，但嘗試重複觸發 | 系統檢查帳號教學狀態，已完成者不再觸發教學流程 |
| 5 | FG 腳本觸發失敗（技術異常） | 顯示錯誤提示並記錄 log；提供「重試」選項，避免玩家卡在教學無法繼續 |
